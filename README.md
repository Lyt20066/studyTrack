# StudyTrack · 学习打卡网站

> 一个开箱即用的学习打卡网站：**注册账号 → 点「开始学习」计时 → 点「结束」自动结算**，
> 自动统计连续打卡天数、生成日历热力图、解锁成就徽章。
> 纯前端实现，**不需要钱包、不需要安装 Node、不需要任何后端服务**，双击 `index.html` 就能用。
>
> 仓库里同时保留了配套的 **Solidity 智能合约**（`contracts/LearningCheckIn.sol`）作为课程作业交付物，
> 但当前网站版本已不接入区块链。

## 一、项目结构

```
learning-checkin-dapp/
├── index.html                    ← 网站（本次交付的主体），已放在项目根目录
├── style.css                       全部样式（浅色主题、响应式、移动端底部导航）
├── app.js                          全部逻辑（账号、计时器、统计、日历、成就、备注、导入导出）
│
├── contracts/
│   └── LearningCheckIn.sol        配套智能合约（Solidity ^0.8.20，作业交付物）
├── test/
│   └── LearningCheckIn.test.js    合约单元测试（需要 Node + Hardhat）
├── scripts/deploy.js              合约部署脚本（本地链 / Sepolia）
├── hardhat.config.js              合约编译与部署配置（可选）
├── package.json                   合约部分的依赖与脚本（可选）
├── .env.example                   Sepolia 部署所需环境变量示例
└── README.md
```

> ⚠️ **`index.html`、`style.css`、`app.js` 必须放在同一个文件夹里**，文件名也不要改。
> 三者通过相对路径互相引用，被拆散就会白屏。为此页面底部内置了**资源自检**：
> 万一真的缺文件，它会在页面顶部弹出明确提示（告诉你缺的是哪个文件），而不是留下白屏。

**网站部分零依赖**：没有 npm 包、没有构建步骤、没有 CDN 外链，三个文件自成一体；
`app.js` 同时兼容 `DOMContentLoaded` 之前与之后两种加载时机，即使被改成 `defer`
或挪到 `<head>` 里也能正常启动。

## 三、网站功能

### 3.1 账号体系（右上角登录）

- **右上角「登录」按钮** → 弹出登录 / 注册弹窗；注册后按钮变成**头像 + 昵称的下拉菜单**
  （含仪表盘、我的记录、个人设置、退出登录）。
- 注册需要：用户名（3–16 位字母/数字/下划线）、昵称、密码（≥ 6 位）、头像（12 个 emoji 可选）。
- 密码使用 **WebCrypto SHA-256 加随机盐**存储，**不保存明文**；若浏览器环境不支持 `crypto.subtle`，
  会自动降级为内置散列并保持功能可用（代码中有注释说明）。
- 同一浏览器可注册多个账号，**数据按账号隔离**，互不影响。

### 3.2 学习计时（自己开启、自己关闭）

这是本次改版的核心：学习时长不再靠手填，而是用计时器如实记录。

| 操作 | 行为 |
|---|---|
| 点「**开始学习**」 | 开始计时，页面顶部大号数字每秒刷新，**浏览器标签页标题也同步显示时间** |
| 点「**结束学习**」 | 结算本段时长，自动写入当天的记录（含**开始时间、结束时间、时长、备注**） |
| 点「**放弃本次**」 | 丢弃这段计时，不写入记录（会二次确认） |
| 「本次备注」输入框 | 开始计时时一并记入，结束后自动清空，方便记录下一段 |

细节规则：

- **一天可以分多段学习**：同日多次计时会**累加到当天**，打卡天数仍只算 1 天。
- **归属日期**：按「开始学习」那一刻所在的日期归属（例如 23:50 开始、00:10 结束，算前一天），
  这样跨午夜的长时间学习不会被拆散。
- **跨刷新不丢**：计时状态存在本地，刷新页面或误关标签页后重新打开，会**自动继续计时**并提示。
- **防忘记关闭**：单段计时超过 8 小时会弹窗提醒，可选择按 8 小时截断或按实际时长记录。
- 仪表盘同时显示**今日累计时长、学习段数、目标完成百分比**，以及当天的每一段明细。

### 3.3 其余功能

| 视图 | 内容 |
|---|---|
| **仪表盘** | 今日计时器、今日目标进度环、累计打卡天数 / 当前连续 / 历史最长 / 累计时长、最近 7 天柱状图、成就进度预览 |
| **打卡日历** | 月视图热力图（颜色分 4 档，学习越久越深），**有备注的日子右上角有橙色小圆点**，**点击任意一天**可查看当天明细、**给每一段或当天写备注**；底部有本月小结（打卡天数 / 学习时长 / 备注条数 / 连续天数） |
| **学习记录** | 按天倒序汇总，每一天列出所有时段的起止时间、时长与备注，**每段和每天都可以直接改备注** |
| **成就** | 8 个徽章：启程、七日坚持、月度学者、十日之约、五十日、十小时、五十小时、专注一日；未解锁显示进度条 |
| **设置** | 修改昵称与头像、设置每日目标、修改密码、导出/导入 JSON 备份、清空数据 |

### 3.4 备注功能（日历 / 学习记录 两处都能编辑）

备注分两级，**两种都可以随时修改，不需要重新打卡**：

| 类型 | 写在哪 | 长度 | 说明 |
|---|---|---|---|
| **每段学习的备注** | 学习记录页每一段的末尾「✎」按钮；日历 → 点某天 → 弹窗里每段也一样 | 60 字 | 记录这一段具体学了什么 |
| **当日备注** | 学习记录页每天卡片底部的「添加备注 / 编辑」；日历 → 点某天 → 弹窗底部 | 200 字 | 记当天的心得、计划或状态 |

怎么用：

- 点「✎」或「添加备注」→ 就地变成输入框 → **回车（段落备注）或 `Ctrl/⌘ + Enter`（当日备注）保存**，也可以点「保存」按钮；
- 按 `Esc` 或点「取消」放弃编辑；已有当日备注时可以点「清除」删掉；
- **可以给没有学习记录的空白日写备注**（比如补记"今天请假"），日历上会用**暖色虚线格子**把这个日子标出来，一眼能看出是"有备注但没学习"；
- **写备注不算打卡**：备注不会增加打卡天数、不影响当前连续与历史最长连续（只有真正产生了学习时段的日子才计入）。纯备注的日子会出现在「学习记录」里，标注为"仅备注，未学习"；
- 备注会随「导出备份」一起导出，导入后完整还原。

其它细节：右下角 Toast 操作提示、响应式布局（≤820px 自动切换为**移动端底部标签栏**）、
标签页标题随计时变化、打印样式（隐藏导航方便截图交作业）等。

## 四、数据存在哪里

**全部数据只保存在你自己浏览器的 `localStorage` 里**，键名为 `studytrack.v1`，不上传任何服务器。

```js
{
  version: 1,
  users: {
    "ming": { username, nickname, avatar, salt, hash, createdAt }
  },
  currentUser: "ming",              // 当前登录的账号
  active: {                         // 正在进行的计时（跨刷新保留）
    "ming": { start: 1757600000000, note: "复习第三章" }
  },
  records: {                        // 每个账号的学习记录
    "ming": {
      "2026-09-11": {               // 以「开始学习」的日期为键
        seconds: 3300,              // 当天累计秒数
        note: "今天状态不错",        // 当日备注（可编辑，可为空）
        segments: [                 // 当天的每一段学习
          { start: 1757600000000, end: 1757601500000, seconds: 1500, note: "复习第三章" }
        ]
      },
      "2026-09-12": {               // 只有备注、没有学习的日子也会保留
        seconds: 0,
        note: "生病请假，明天补上",
        segments: []
      }
    }
  },
  settings: { "ming": { goal: 60 } } // 每日目标（分钟）
}
```

因为存在本地，请注意两点：**① 换电脑或清理浏览器数据会丢失，建议定期在「设置」里导出备份；
② 不要用无痕模式长期使用。**

## 五、课堂演示脚本（约 3 分钟）

1. **注册**：右上角「登录」→ 切到「注册」→ 选个头像，用户名 `demo`、密码 `123456` → 创建账号。
   → 右上角变成头像下拉菜单。
2. **开始学习**：仪表盘点「开始学习」，大号计时器开始跳动，**看一眼浏览器标签页标题**也在走。
3. **写点东西再结束**：备注填「第一章 绪论」，点「结束学习」→ Toast 提示本次时长，今日累计出现。
   （想演示得快一点，可以先开始、等十几秒再结束，时长会如实显示为「xx 秒」。）
4. **再来一段**：再点「开始学习」→「结束学习」，今日变成 **2 段**，累计时长叠加，**打卡天数仍为 1**。
5. **看日历**：切到「打卡日历」，今天已经有颜色了；**点今天**能看到两段的起止时间与备注。
6. **加备注**：在刚打开的弹窗里，点某一段后面的「✎」写「第一章 绪论」，回车保存；
   再点底部的「添加备注」，给当天写一句「状态不错」并保存 → **日历上今天多了一个橙色小圆点**。
7. **给空白日写备注**：点一个还没学习过的日子 → 底部「添加备注」→ 写「今天请假」→ 保存。
   → 日历上这天变成**暖色虚线格子**，但**打卡天数和连续天数完全没变**（备注不等于打卡）。
8. **在学习记录页改备注**：切到「学习记录」，每段右侧同样有「✎」，每天的卡片底部也能改当日备注。
9. **看连续天数**：连续几天打卡后，「当前连续」自动增长；中间断一天再打卡，连续天数会**重新从 1 开始**，
   而「累计打卡天数」不受影响。
10. **看成就**：切到「成就」，解锁的徽章点亮，未解锁的显示进度条（例如 5 / 7 天）。
11. **换账号验证数据隔离**：退出登录 → 注册第二个账号 → 仪表盘是全新的 0，
    说明数据按账号隔离且只存在本机。
12. **导出备份**：设置页「导出备份（JSON）」→ 打开文件可以看到完整的数据结构（含备注）。

## 六、配套智能合约（作业交付物）

网站版本已经不接链，但 `contracts/LearningCheckIn.sol` 完整保留，可用于作业中的链上部分。

### 6.1 合约功能

| 需求 | 实现方式 |
|---|---|
| 钱包注册 | `register()`，每个地址一次，用 `bool registered` 标记 |
| 每日打卡、一天一次 | `checkIn()` 中 `require(p.lastDay != today)` |
| 记录总打卡数与连续天数 | `Profile.totalDays` + `Profile.streak` / `maxStreak` |
| 7 天 / 30 天成就 | `badge7` / `badge30` 两个 `bool`，达标写入 `true` 且不撤销 |
| 不涉及代币与资金 | 无 `payable`、无转账、无 ERC20 |
| 记录时间与次数 | `Record{ timestamp, day, studyMinutes, streakAt, note }` |
| 漏打卡自动清零 | `_syncStreak()` 在打卡前与查询时判断，断卡则清零 |
| 按地址查历史 | `getRecords()` / `getRecordsPage()` / `getCheckedDays()` |

### 6.2 关键设计：天序号

```solidity
uint256 public constant SECONDS_PER_DAY = 1 days;
uint256 public constant TZ_OFFSET = 8 hours;          // 北京时间日切，改成 0 即 UTC
function _currentDay() internal view returns (uint256) {
    return (block.timestamp + TZ_OFFSET) / SECONDS_PER_DAY;
}
```

用整数除法得到「天序号」，同一序号即同一天，逻辑简单且省 Gas。

### 6.3 部署（Remix）

1. 打开 <https://remix.ethereum.org>，新建 `LearningCheckIn.sol` 并粘贴合约代码。
2. **Solidity Compiler** 选 `0.8.20`，点 **Compile**。
3. **Deploy & Run Transactions**：
   - Environment 选 **`Browser Extension`**（旧版 Remix 里叫 `Injected Provider - MetaMask`，是同一项）；
   - **确认 `Value` 为 0**（本合约构造函数非 payable，带了 ETH 会直接 revert）；
   - 钱包切到 **Sepolia** 或本地网络，点 **Deploy**。
4. 复制部署出的合约地址备用。

> ⚠️ 不要用 `Remix VM` 部署来做演示——那是浏览器内的沙盒链，钱包与外部程序都访问不到。

### 6.4 部署（Hardhat，可选）

```bash
npm install
npx hardhat test                                        # 运行合约单元测试
npx hardhat node                                        # 终端 A：本地链
npx hardhat run scripts/deploy.js --network localhost    # 终端 B：部署
# Sepolia：复制 .env.example 为 .env 并填好 RPC 与私钥，然后
npm run deploy:sepolia
```

## 七、常见问题

**Q1：为什么点「开始学习」没反应？**
未登录时会自动弹出登录框。如果连登录框也没出现，请确认浏览器允许了本地存储（无痕模式可能禁用）。

**Q2：网页上的数据会上传到服务器吗？**
不会。没有任何网络请求，所有读写都在浏览器本地的 `localStorage`。

**Q3：密码安全吗？**
密码以「随机盐 + SHA-256」的摘要形式保存，浏览器里看不到明文。但这只是本地演示级方案：
`localStorage` 对同一台电脑上的其他程序并不保密，**请不要使用你其它网站的真实密码**。

**Q4：手填学习时长的功能去哪了？**
按需求改成了「自己开启、自己关闭」的计时器，时长由计时器如实记录，避免手填虚报。
如果只是想补录时长，可以先点开始、再立刻结束，然后按实际情况在记录里查看（备注可写明）。

**Q5：一天学习了好几次，为什么打卡天数只加 1？**
这是刻意的设计：**打卡天数 = 有学习记录的天数**，同日多段只算 1 天，
但时长会如实累加，日历上也能看到当天所有时段。连续天数按「天」计算，因此不受影响。

**Q6：计时器忘记关了怎么办？**
单段超过 8 小时会弹窗提醒，可选择按 8 小时截断或按实际时长记录。刷新页面不会中断计时（会自动继续）。

**Q7：契约/钱包相关报错（`Gas estimation failed`、找不到 `Injected Provider - MetaMask`）？**

- Remix 新版把 `Injected Provider - MetaMask` 改名为 **`Browser Extension`**，且**未安装钱包扩展时该选项不显示**；
  可在 Remix 页面按 `F12` 输入 `window.ethereum` 检查扩展是否注入成功。
- 部署报 `missing revert data (action="estimateGas")`：依次检查 ①`Value` 是否为 0；
  ②钱包余额是否为 0（Sepolia 需领测试币）；③网络是否为 Sepolia；④目标链太老则把
  **EVM Version** 从 `shanghai` 改成 `paris` 重新编译（`0.8.20` 默认生成 `PUSH0` 指令，
  实测本合约 `shanghai` 有 88 个 `PUSH0`、`paris` 为 0 个）。**不要盲目点 "force sending"。**
- 敲 `npm install` 提示「无法将"npm"项识别为 cmdlet」：这台机器还没装 Node.js，
  去 <https://nodejs.org> 装 LTS 版并重开终端即可；只用网站功能的话**完全不需要 Node**。

**Q8：怎么看我的数据是不是丢了？**
设置页「导出备份」会下载一个 JSON，里面包含个人资料、每日目标与全部学习记录（含备注）；
换电脑时用「导入备份」恢复即可。

**Q9：我给某天写了备注，为什么打卡天数没变？**
这是刻意的设计：**备注 ≠ 打卡**。只有真正产生了学习时段的日子才算打卡日，否则随便写条备注就能刷连续天数了。
所以「给空白日写备注」只会让这天在日历上显示为暖色虚线格子（表示有备注没学习），
不影响打卡天数与连续天数。想补记某天真的学过，请用计时器记录，或参考 Q4 的做法。
